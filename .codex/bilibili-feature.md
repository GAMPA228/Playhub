# B站视频与直播接入

## 范围与实现

- 新增第四个“视频解析”导航页，仅接 B站普通作品、分 P、分享短链和直播间；原影视源、电视直播、存储键和默认首页不变。
- 独立后端解析服务，调用平台网页接口；参考 YunX 的分层思路，不移植其 AGPL 源码或桌面组件。不增加 Chromium、FFmpeg、账号转存或下载器。
- 视频使用 AVC + AAC DASH，由标准 MPD 和网页 DASH 播放器同步音视频；直播优先 AVC HLS。可选 `BILIBILI_COOKIE` 仅在后端用于平台接口，凭证不写入共享源配置、不返回前端或记录日志。
- 媒体同源流式代理：会话绑定、随机播放授权、签名资源、CDN 白名单、逐跳重定向校验、Range 透传和 HLS 子资源重写；限制播放上下文数量及并发，避免复用 Spider 池。

## 验收

- 首页/直播/观看记录/视频解析四标签、默认首页、解析页高亮、窄屏标签可达且不引入页面横向溢出。
- 普通视频及分 P/清晰度切换有画面有声音可拖动；直播开播/未开播提示及地址刷新明确；错误/加载/取消和旧响应隔离完整。
- 自动测试覆盖解析输入、上游失败、音轨、直播状态、代理 Range/HLS/授权与恶意 URL；前端构建及原测试回归；最终 JAR 资产一致。
- 公网样例仅验证能公开访问的内容，不读取真实账号凭证，不改变账号/网盘数据。外网不可验证的项目明确记录，不将模拟播放当作真实平台实播。
- 用户已授权本次完成后提交并推送 main。保留默认 Docker 服务/JAR 名称，部署只增加可选 Cookie 配置，无数据迁移；可回滚旧完整镜像。
